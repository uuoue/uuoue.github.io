# PHP-文件管理



## 文件上传-上传构架补充


| 架构 | 说明 | 安全特点 |
|---|---|---|
| 上传到服务器本身磁盘（与源码在一起） | 文件和源码同服务器 | 文件可被解析，后门可执行，风险最高 |
| 云产品 OSS 对象存储 | 文件存到阿里云/腾讯云等 OSS | 文件只存储不解析，后门无法执行；但可能泄露 AccessKey |
| 上传到其他域名 | 如 `www.xiaodi8.com` → `upload.xiaodi8.com` | 独立存储域名，通常不解析脚本，风险较低 |

## 文件包含


| 函数 | 特点 |
|---|---|
| `include()` | 包含出错后脚本继续执行 |
| `require()` | 包含出错后脚本停止执行 |
| `include_once()` | 已包含则不再包含 |
| `require_once()` | 已包含则不再包含 |


如果包含的文件名来自用户可控参数：

```php
include （$_GET['file']）;
```

![image-20261024091600655](../images/image-20261024091600655.png)


攻击者可以包含任意文件：

```text
?file=upload.html
?file=index.php
?file=1.txt
```


漏洞成因通用公式

> **可控变量 + 危险函数 = 漏洞**

- 可控变量：用户提交的恶意数据。
- 危险函数：决定漏洞类型。
  - 文件包含函数 → 文件包含漏洞
  - 文件上传函数 → 文件上传漏洞
  - 命令执行函数 → 命令执行漏洞
  - 文件删除函数 → 任意文件删除
  - 文件读取函数 → 任意文件读取

### 核心知识点

- `$_GET`：获取 URL 参数
- `is_file()`、`is_dir()`：判断文件或目录
- `opendir()`、`readdir()`：遍历目录
- `switch`：根据操作类型执行不同逻辑
- `unlink()`：删除文件
- `file_get_contents()`：读取文件内容
- `fwrite()`：写入文件内容
- `foreach`：遍历文件列表

### 文件下载：
- 修改HTTP头实现文件读取解析下载：

## 文件管理功能的安全问题

1. 目录遍历

- `path` 参数可控，可用 `../` 跨目录。
- 可浏览服务器任意目录，甚至 C 盘。
- 造成信息泄露。

2. 任意文件读取

- 编辑功能读取文件内容。
- 若路径可控，可读取任意文件。

3. 任意文件下载

- 下载功能路径可控。
- 可下载服务器任意文件，如配置文件、源码。

 4. 任意文件删除

- 删除功能路径可控。
- 可删除服务器任意文件，甚至整个目录内容。

5. 任意文件写入/编辑

- 编辑功能路径可控。
- 可写入任意文件，可能写入后门。

6. 命令执行

- 如果删除使用 `system("del " . $file)` 等系统命令。
- 参数可控时可能造成命令注入。
- 例如：

```text
?path=1.txt & ping xxx
```

- 命令拼接不当可执行任意系统命令。

7. 漏洞成因


> **可控变量 + 危险函数 = 漏洞**

- 使用 `unlink` → 任意文件删除
- 使用 `system` → 命令执行
- 使用 `file_get_contents` → 任意文件读取
- 使用 `readfile` + 下载头 → 任意文件下载
- 使用 `fopen` + `fwrite` → 任意文件写入
